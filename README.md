This is a simple calculator that I made purely because I wanted to create something.

Modest desktop calculator built with Python and Tkinter.

## It features
* **Matrix Visual Style**: Custom dark background (`#0d2525`) with retro green typography.
* **Input Validation**: Rejects invalid character typing dynamically in real time to prevent syntax errors.
* **Smart Backspace (`⌫`)**: Safely handles single-character deletion and resets automatically if the screen displays an error.
* **Error Prevention**: Evaluates expressions inside a safety block to handle division by zero or broken syntax without crashing.
* **International Decimal Support**: Comma `,` key mapped directly to decimal point `.` logic.
(Will probably work to add more functions or clean the UI or something else)
## You need
* Python 3.x installed on your computer.
